# واصل — منصة حملات واتساب متعددة الفروع

تطبيق ويب (Flask + Selenium) لإدارة حملات واتساب: حساب عام واحد يسجَّل بالبريد
الإلكتروني وكلمة المرور، ومنه يُنشئ حسابات فروع مستقلة (بريد وكلمة مرور خاصين بكل
فرع) تسجّل دخولها وتدير حساباتها وحملاتها بمعزل تام عن باقي الفروع. كل حساب (عام
أو فرع) يقدر يربط عدة أرقام واتساب، ويرسل حملات نصية/صور/فيديو/ملفات فورية أو
مجدولة بموعد واحد أو **مقسّمة على عدة أيام** (مثلاً: 80 رقم بمعدل 20 يومياً على 4
أيام تلقائياً). ما فيه اشتراكات أو فترة تجريبية — أي حساب مسجّل يستخدم المنصة
كاملة مباشرة.

## المزايا

- تسجيل دخول/حساب بالبريد الإلكتروني وكلمة المرور فقط.
- حساب عام ← فروع: كل حساب عام ينشئ فروعاً ببيانات دخول مستقلة، وكل فرع بياناته
  (حسابات واتساب، حملات، سجل) معزولة تماماً.
- أدمن المنصة حساب ثابت (بريد وكلمة مرور من `ADMIN_EMAIL`/`ADMIN_PASSWORD`) بدل
  "أول من يسجّل يصير أدمن" — يُنشأ أو يُحدَّث تلقائياً بكل إقلاع للسيرفر.
- حملات واتساب: أرقام تُكتب يدوياً أو تُستورد من ملف Excel، رسالة نصية مع حقل
  رابط منفصل (يُدمجان تلقائياً بالرسالة المرسلة)، ومرفق صورة/فيديو/ملف اختياري.
- جدولة الحملة: إرسال فوري، أو بموعد واحد، أو تقسيم القائمة على عدة أيام (حدّد
  عدد الأرقام باليوم أو عدد الأيام) مع وقت إرسال يومي ثابت — تشتغل تلقائياً حتى
  لو السيرفر انطفى وانرجع اشتغل (يلحق الدفعات المتأخرة).
- رد آلي بكلمات مفتاحية أو بالذكاء الاصطناعي (DeepSeek، يفعّله الأدمن من لوحته).
- تطبيق PWA (يُضاف للشاشة الرئيسية)، وضع داكن/نهاري، إشعارات فورية.

## التشغيل

```bash
pip install -r requirements.txt
python webapp.py
```

ثم افتح `http://localhost:5000` (أو `http://IP_السيرفر:5000` على VPS). يحتاج
Chrome/Chromium و chromedriver مثبّتين على نفس الجهاز (تحكم كل حساب واتساب عبر
متصفح Selenium منفصل، ويربط جلسته بمجلد `wa_sessions/` فلا يحتاج مسح QR من جديد
بعد كل إعادة تشغيل).

### بيانات دخول الأدمن

قبل أي تشغيل فعلي على الإنترنت، غيّر بيانات دخول الأدمن الثابتة، إما بتعديل
`ADMIN_EMAIL`/`ADMIN_PASSWORD` أعلى `webapp.py` مباشرة، أو بمتغيرات بيئة (الأفضل
حتى لا تُحفظ كلمة المرور الحقيقية بالكود):

```bash
export ADMIN_EMAIL="you@example.com"
export ADMIN_PASSWORD="اختر-كلمة-مرور-قوية"
python webapp.py
```

أي شخص آخر يسجّل حساباً جديداً من `/signup` يصير حساباً عاماً عادياً (مو أدمن)،
يقدر يضيف حسابات واتساب وينشئ فروعاً تحته مباشرة.

## ملاحظة مهمة

التحكم بواتساب هنا عبر أتمتة متصفح (Selenium) لواجهة واتساب ويب، وهذا يخالف
شروط استخدام واتساب الرسمية للإرسال الآلي/الجماعي. استخدمه على مسؤوليتك، ولأرقام
وافقت فعلاً على استقبال رسائلك (تسويق لعملائك الحاليين مثلاً)، لا لإرسال رسائل
غير مرغوبة أو حملات جماعية عشوائية. ولأن "الرد الآلي" يعتمد على مراقبة دورية
لواجهة واتساب ويب (ما فيه حدث رسمي "رسالة جديدة")، فهو مبني على تخمين لمحددات
DOM قابلة للتغيّر مع كل تحديث لواتساب ويب، وقد يحتاج جولة تصحيح لو ما اشتغل من
أول مرة.
