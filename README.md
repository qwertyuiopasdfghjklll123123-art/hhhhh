# واصل — منصة حملات واتساب متعددة الفروع (PHP لاستضافة cPanel)

منصة لإدارة حملات واتساب لعدة فروع، تشتغل على **استضافة cPanel عادية (PHP + MySQL)**
بدون VPS، **وبدون تثبيت أي برنامج أو إضافة** على أجهزة الفروع.

## كيف يشتغل الإرسال

### 1) تلقائي من سيرفرك الخاص — بدون اشتراك ولا حدود (المستحسن)

مجلد **`wasel-gateway`** (البوابة الخاصة) هو تطبيق Node.js صغير يشتغل **على استضافتك نفسها**
من cPanel ← **Setup Node.js App**، ويشغّل "واتساب ويب" لأرقام فروعك (بمكتبة Baileys المفتوحة
المصدر) — نفس الشي اللي تسويه الخدمات المدفوعة، بس على سيرفرك:

- **ما فيه أي اشتراك** ولا تسجيل بأي موقع، **ولا حدود باقات** على عدد الرسائل أو الأرقام.
- الأدمن يفعّلها **مرة وحدة** (5 دقايق)، وبعدها أي فرع: "حسابي" ← "تفعيل الإرسال التلقائي" ←
  **سيرفرك الخاص** ← "حفظ وربط" ← يمسح رمز QR من واتساب جواله (أو يكتب رمز من 8 خانات).
- الموقع يرسل الحملات بنفسه بموعدها، رقم رقم بمهلة، مع "يكتب..." قبل كل رسالة حتى يبين طبيعي،
  ويتأكد إن الرقم عنده واتساب قبل الإرسال.

الشرط الوحيد: استضافتك تشغّل تطبيقات **Node.js** — بـ cPanel و DirectAdmin اسمها **Setup Node.js App**
(أغلب الاستضافات اللي تستخدم CloudLinux)، وبهوستنجر باقات Business و Cloud (Websites ← Add Website ←
Node.js). إذا ما موجودة: اطلبها من شركة الاستضافة، أو شغّل البوابة على أي سيرفر رخيص، أو استخدم الطريقة 2.

### 2) تلقائي عبر خدمة جاهزة (Green-API / UltraMsg)

إذا ما تريد/ما تقدر تشغّل البوابة الخاصة: تسجّل بخدمة **Green-API** أو **UltraMsg** (تسجيل بالبريد
فقط) وتلصق رقم الـ Instance والرمز بالموقع وتمسح QR. هذي الخدمات **باشتراك شهري** وباقاتها
المجانية للتجربة بس.

### 3) يدوي بالضغط (بدون أي إعداد)

للحساب اللي ما مربوط: زر **"إرسال عبر واتساب"** يفتح واتساب (جوال أو كمبيوتر) والرقم والرسالة
جاهزين، تضغط إرسال وترجع للموقع تلقى الرقم الجاي جاهز. هذي الطريقة تبقى متاحة تلقائياً كبديل إذا
رقم مربوط انفصل.

## تفعيل البوابة الخاصة (مرة وحدة — الأدمن)

بلوحة تحكم واصل ← **"البوابة الخاصة"** اختر لوحة استضافتك (**cPanel** أو **DirectAdmin** أو
**Hostinger hPanel**) وتطلع لك الخطوات مع المسارات الصحيحة لموقعك. تعرف لوحتك من اسمها أعلى
صفحة الاستضافة (هوستنجر لوحتها بنفسجية واسمها hPanel). إذا مسار موقعك يبدأ بـ
`domains/موقعك/public_html` فلوحتك غالباً هوستنجر أو DirectAdmin.

### cPanel أو DirectAdmin

مجلد `wasel-gateway` موجود أصلاً داخل ملفات الموقع بعد ما ترفعها.

1. افتح **Setup Node.js App** — بـ cPanel تلقاه بالصفحة الرئيسية (قسم Software)، وبـ DirectAdmin
   بقسم **Extra Features** أو **Advanced Features** (إذا ما موجود: اطلب من الاستضافة تفعّل
   CloudLinux Node.js Selector) ← **Create Application**:
   - **Node.js version**: 20 أو أحدث
   - **Application root**: مسار مجلد البوابة (مكتوب لك بلوحة التحكم، مثل
     `public_html/wasel-gateway` أو `domains/موقعك/public_html/wasel-gateway`)
   - **Application URL**: موقعك + `wasel-gw`
   - **Application startup file**: `app.js`
   - ← **Create**
2. اضغط **Run NPM Install** (ينزّل مكتبة واتساب — دقيقة أو دقيقتين) وبعدها **Restart**.
3. بموقع واصل: لوحة التحكم ← "البوابة الخاصة" ← الصق رابط التطبيق (مثل `https://موقعك/wasel-gw`)
   ← **حفظ واختبار** ← لازم تطلع "شغّالة". المفتاح السري ينكتب تلقائياً بملف `wasel-key.php`
   داخل مجلد البوابة.

### Hostinger (hPanel)

هوستنجر يشغّل تطبيقات Node.js بباقات **Business** و **Cloud** (إذا ما تلقى خيار Node.js فباقتك ما تدعمه).

1. بلوحة تحكم واصل ← "البوابة الخاصة" ← اختر Hostinger ← **تحميل wasel-gateway.zip** (جاهز وفيه
   المفتاح السري — لا تشاركه).
2. hPanel ← **Websites** ← **Add Website** ← **Node.js** ← ارفع الملف (Upload)، وبالإعدادات:
   - **Node.js version**: 20 أو أحدث
   - **Entry file**: `app.js` — **Start command**: `npm start` — **Build command**: فاضي
   - **Environment variables**: ما تحتاج (إذا طلب `WASEL_KEY` الصق المفتاح من زر "نسخ المفتاح")
3. اختر له دومين فرعي (مثل `gw.موقعك`) أو الدومين المؤقت ← **Deploy**.
4. بموقع واصل: الصق رابط التطبيق (مثل `https://gw.موقعك`) ← **حفظ واختبار**.

### بعدها (لكل اللوحات)

فعّل **"الإرسال بالخلفية" (Cron)** من نفس الصفحة — مهم: يبقي البوابة صاحية والأرقام متصلة على
مدار الساعة. الخطوات تتغيّر حسب لوحتك (بهوستنجر: hPanel ← Advanced ← Cron Jobs ← النوع PHP ←
مسار ملف `cron.php` ← كل دقيقة).

جلسات الواتساب تنحفظ بمجلد `~/.wasel-sessions` خارج الموقع — ما تنفتح من المتصفح، وترجع تتصل
لحالها بعد أي إعادة تشغيل بدون مسح QR من جديد. إذا غيّرت المفتاح السري: بـ cPanel/DirectAdmin
ينكتب تلقائياً، وبهوستنجر حمّل ملف البوابة من جديد وأعد رفعه (Redeploy).

**على سيرفر عادي (VPS)**: فك ملف البوابة المحمّل ثم `npm install && PORT=3000 node app.js`
(ويُفضّل pm2 حتى يبقى شغّال)، والصق رابطه بلوحة التحكم.

## تفعيل الإرسال عبر خدمة جاهزة — خطوة بخطوة

### Green-API (فيها باقة مجانية للتجربة)

1. افتح [green-api.com](https://green-api.com/) وسجّل حساب بالبريد الإلكتروني.
2. من لوحة التحكم ([console.green-api.com](https://console.green-api.com/)) أنشئ **Instance**:
   - باقة **Developer** مجانية — للتجربة فقط (تسمح بعدد قليل جداً من الأرقام).
   - باقة **Business** للإرسال الحقيقي — اشتراك شهري لكل رقم (حوالي 12 دولار، تأكد من السعر بموقعهم).
3. انسخ من صفحة الـ Instance: `idInstance` و`apiTokenInstance` و`apiUrl`.
4. بموقعك: "حسابي" ← "تفعيل الإرسال التلقائي" ← Green-API ← الصقها ← "حفظ وربط" ← امسح الرمز.

### UltraMsg

1. افتح [ultramsg.com](https://ultramsg.com/) وسجّل حساب (فيها تجربة مجانية لأيام، بعدها اشتراك
   شهري لكل رقم — حوالي 39 دولار، تأكد من السعر بموقعهم).
2. أنشئ Instance وانسخ `Instance ID` و`Token`.
3. بموقعك: "تفعيل الإرسال التلقائي" ← UltraMsg ← الصقها ← "حفظ وربط" ← امسح رمز QR.
   (UltraMsg تدعم مسح QR فقط — إذا الموقع مفتوح على نفس الجوال افتحه من جهاز ثاني وقت الربط.)

الموقع يجرّب البيانات قبل ما يحفظها، وإذا فيها غلط يقولك فوراً. الرمز السري (Token) ينحفظ
بقاعدة بياناتك فقط وما يطلع للمتصفح أبداً.

### الإرسال بالخلفية (حتى لو الموقع مسكّر) — للأدمن، مرة وحدة

بدون هذي الخطوة، الإرسال التلقائي يشتغل **ما دام الموقع مفتوح بأي متصفح** (أي جهاز لأي فرع).
حتى يرسل والكل مسكّر الموقع:

- **cPanel ← Cron Jobs** ← Common Settings: **Once Per Minute** ← الصق الأمر الجاهز من
  "لوحة التحكم ← الإرسال التلقائي بالخلفية" (فيه مسار موقعك الصحيح)، مثل:

  ```
  /usr/local/bin/php -q /home/اسم_حسابك/public_html/cron.php >/dev/null 2>&1
  ```

- **أو بدون Cron الاستضافة**: أي خدمة Cron مجانية (مثل cron-job.org) تفتح كل دقيقة الرابط
  الجاهز بنفس الصفحة: `https://دومينك/cron.php?key=...` (فيه مفتاح سري — لا تشاركه، وتقدر
  تغيّره من نفس الصفحة).

لوحة التحكم تبيّن إذا الإرسال بالخلفية شغّال وآخر وقت اشتغل فيه.

## المزايا

- **أدمن واحد ثابت بالكود** (بريد وكلمة مرور بملف `inc/core.php`) — ما فيه تسجيل حساب من الموقع.
- **الأدمن فقط ينشئ الفروع**: اسم + بريد + كلمة مرور (أو مولّدة تلقائياً)، ويقدر يغيّر كلمة مرور
  أي فرع (يطلع من كل أجهزته) أو يحذفه.
- **صلاحيات الفرع**: حسابات واتساب، الحملات، والإشعارات فقط — وبياناته معزولة عن باقي الفروع.
- **حملات نصية**: حقل للنص وحقل للرابط (يُضاف بآخر الرسالة)، بدون مرفقات صور/ملفات.
- **الأرقام** تُكتب أو تُرفع من Excel (.xlsx) أو CSV — يتعرّف على عمود الأرقام تلقائياً،
  ويحذف المكرر والناقص، ويقبل الأرقام العربية (٠٧٧٠…).
- **رمز الدولة**: قائمة أعلى حقل الأرقام (العراق 964 افتراضياً) — اكتب الأرقام محلياً
  (07701234567) والرمز ينضاف تلقائياً. الرقم المكتوب دولياً (+971…) يبقى كما هو.
- **الجدولة**: فوري، أو بموعد واحد، أو **تقسيم على أيام** (مثلاً 80 رقم ← 20 يومياً على 4 أيام).
- **متابعة**: تقدّم كل حملة، جدول الأيام، الأرقام اللي ما وصلتها الرسالة (مع السبب — مثل
  "الرقم ما عنده واتساب" اللي تبلّغ عنه الخدمة)، **إيقاف مؤقت/استئناف**، وإلغاء يوم أو حملة.
- **حماية من التكرار**: قفل بقاعدة البيانات يضمن ما تنرسل نفس الرسالة مرتين، حتى لو الـ Cron
  وأكثر من متصفح اشتغلوا بنفس الوقت.
- **إذا صارت مشكلة بالربط** (انفصل الرقم، البوابة طافية، انتهت الباقة، رمز غلط): الإرسال يتوقف لهذا الرقم،
  يوصل إشعار للفرع، والرسائل تبقى بالدور وتكمّل أول ما تنحل المشكلة (أو ترسلها يدوياً).
- **إشعارات** داخل الموقع وبالمتصفح (بدأ الإرسال، خلصت رسائل اليوم، اكتملت الحملة، انفصل الرقم…).
- **لوحة الأدمن**: إحصائيات كل الفروع، ترتيب الفروع حسب نسبة النجاح، حالة الإرسال بالخلفية،
  تغيير اسم وشعار الموقع.
- **تطبيق PWA** يتثبّت على الجوال والكمبيوتر (اختياري)، وتصميم لسطح المكتب يتحول لقائمة على الجوال.

## التثبيت على cPanel (مرة وحدة)

1. **ارفع الملفات**: cPanel ← File Manager ← `public_html` (أو مجلد فرعي) ← Upload لملف
   الـ zip ← Extract. لازم يكون `index.php` مباشرة داخل المجلد.
2. **أنشئ قاعدة بيانات**: cPanel ← MySQL Databases:
   - أنشئ قاعدة بيانات (مثلاً `user_wasel`) ومستخدم بكلمة مرور.
   - Add User To Database ← اختر ALL PRIVILEGES.
3. **افتح المثبّت**: `https://دومينك/install.php` ← أدخل بيانات قاعدة البيانات (السيرفر
   غالباً `localhost`) ← "تثبيت النظام الآن".
4. **احذف `install.php`** من مدير الملفات بعد نجاح التثبيت (للأمان).
5. **ادخل بحساب الأدمن** من `https://دومينك/` وفعّل "الإرسال بالخلفية" (القسم أعلاه).

المتطلبات: PHP 7.4 أو أحدث (يُفضّل 8.1+) مع `pdo_mysql`، و**`curl`** (للإرسال التلقائي).
ويُفضّل تفعيل `zip` (لقراءة Excel) و`gd` و`mbstring` من cPanel ← Select PHP Version ←
Extensions (المثبّت يفحصها لك). فعّل شهادة SSL المجانية (AutoSSL) حتى يشتغل الموقع على `https`.

**تحديث نسخة سابقة**: ارفع الملفات الجديدة فوق القديمة (بدون حذف `config.php` ومجلد
`uploads`) — قاعدة البيانات تتحدّث تلقائياً أول ما تفتح الموقع، وكل البيانات تبقى. الحسابات
القديمة تبقى "يدوي" لحد ما تفعّل لها الإرسال التلقائي.

## الاستخدام اليومي للفرع

1. **حسابي** ← "إضافة حساب": اسم ورقم الواتساب، واختر **"تلقائي عبر API"** ← اربطه (مرة وحدة).
2. **الحملات** ← حملة جديدة: الأرقام، النص، الرابط، والتوقيت ← "حفظ الحملة".
3. **خلاص** — الحملة تنرسل لحالها. تتابعها من بطاقة "يُرسل تلقائياً الآن" أعلى صفحة الحملات،
   وتقدر توقفها مؤقتاً أو تلغيها من صفحة الحملة.

### من الجوال (بدون تحميل أي شي)

- افتح رابط الموقع بمتصفح الجوال (كروم أو سفاري) وسجّل الدخول مع **"تذكرني"** — يبقى داخل 30 يوم.
- ربط الرقم من نفس الجوال: الموقع يعرض لك **رمز من 8 خانات** بدل QR (Green-API) تكتبه بواتساب.
- على أندرويد يظهر زر **"اختيار أرقام من جهات اتصال الجوال"** لإضافة أرقام الحملة من الأسماء المحفوظة.
- شريط "أضف أيقونة الموقع للشاشة الرئيسية" **اختياري** — إذا ما تريده اضغط ×.

## بيانات دخول الأدمن

موجودة أعلى ملف `inc/core.php`:

```php
define('ADMIN_EMAIL', 'fastcrand@gmail.com');
define('ADMIN_PASSWORD', 'fastcrand1');
```

لتغييرها عدّل السطرين وارفع الملف من جديد. لا تشارك هذا الملف ولا تخلّي المستودع عام.

## ملفات المشروع

| الملف/المجلد | الوظيفة |
|---|---|
| `index.php` | الموقع: شاشة الدخول، لوحة التحكم، وواجهة JSON (`?api=`) |
| `cron.php` | الإرسال التلقائي بالخلفية (Cron بـ cPanel أو رابط بمفتاح سري) |
| `install.php` | المثبّت: ينشئ الجداول ويكتب `config.php` |
| `wasel-gateway/` | البوابة الخاصة: تطبيق Node.js (Baileys) يشغّل واتساب ويب على استضافتك — بدون اشتراك |
| `inc/gateway.php` | الربط مع البوابة الخاصة و Green-API و UltraMsg (الحالة، QR، رمز الربط، الإرسال) |
| `inc/autosend.php` | محرك الإرسال التلقائي (المهلة، المحاولات، القفل، تحديث الحالات) |
| `inc/` | باقي منطق النظام (قاعدة البيانات، الحملات، الصلاحيات) — محمي من المتصفح |
| `assets/` | التصميم والواجهة والخطوط والأيقونات (كلها محلية بدون مواقع خارجية) |
| `uploads/` | شعار الموقع المرفوع |
| `config.php` | بيانات قاعدة البيانات — ينشئه المثبّت على السيرفر فقط (مستثنى من Git) |

## أسئلة شائعة

- **الحملة مكتوب عليها "متوقفة — الرقم غير متصل"**: افتح "حسابي" وشوف سبب الحالة تحت الرقم
  (انفصل، انتهت الباقة، رمز غلط...) ← "ربط الرقم" أو "إعدادات الربط". الرسائل تبقى بالدور
  وتكمّل تلقائياً بعد ما تنحل، أو اضغط "إرسال يدوي" بصفحة الحملة.
- **الإرسال التلقائي يوقف لما أسكّر الموقع**: فعّل "الإرسال بالخلفية" (Cron) من لوحة التحكم.
- **"تعذّر الاتصال بخدمة الواتساب"**: تأكد إن إضافة cURL مفعّلة، وإن الاستضافة تسمح بالاتصال
  الخارجي (بعض الاستضافات المجانية تمنعه).
- **"البوابة الخاصة ما ترد"**: بلوحة الاستضافة تأكد إن تطبيق Node.js شغّال (Restart بـ cPanel/DirectAdmin،
  أو Redeploy بهوستنجر)، وإن الرابط بلوحة التحكم هو نفس رابط التطبيق.
- **"تعذّر الاتصال بخوادم واتساب من السيرفر"**: الاستضافة تمنع اتصال تطبيق Node.js بواتساب —
  اسأل شركة الاستضافة، أو شغّل البوابة على سيرفر ثاني أو استخدم خدمة جاهزة.
- **الرقم ينفصل لحاله بعد أيام**: فعّل "الإرسال بالخلفية" (Cron) — بدونه البوابة تطفى لما ما أحد
  فاتح الموقع، وواتساب يفصل الأجهزة المرتبطة اللي تبقى طافية أكثر من أسبوعين.
- **رقم انحسب "ما وصلت"**: السبب مكتوب جنبه بصفحة الحملة — غالباً الرقم ما عنده واتساب.
- **أريد أرجع للإرسال اليدوي**: "إعدادات الربط" ← "رجوع للإرسال اليدوي".
- **بالإرسال اليدوي الزر يفتح واتساب ويب وأريد تطبيق الكمبيوتر**: بشاشة الإرسال ← "نص الرسالة
  وطريقة فتح واتساب" ← "تطبيق واتساب على الجهاز".

## ملاحظة مهمة

البوابة الخاصة و Green-API و UltraMsg كلها طرق **غير رسمية** (تشغّل واتساب ويب). "بدون حدود"
يعني بدون حدود باقات — بس واتساب نفسه عنده حماية من الإزعاج، وإرسال رسائل كثيرة لأرقام ما
تعرفك يمكن يسبب **حظر الرقم**. أرسل لعملائك اللي وافقوا يستلمون رسائلك، خلّي
المهلة 15–30 ثانية أو أكثر، ووزّع القوائم الكبيرة على أيام (ميزة التقسيم)، وابدأ بأعداد قليلة
للرقم الجديد. الأفضل تستخدم رقم مخصص للحملات مو رقمك الشخصي.
