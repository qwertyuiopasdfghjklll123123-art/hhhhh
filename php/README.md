# fastcrand — نسخة PHP / MySQL

نسخة PHP+MySQL موازية لنسخة Flask/SQLite الأصلية (`app.py`)، تُبنى بالتدريج
بنفس طريقة بناء النسخة الأصلية على مدار هذا المشروع: أساس كامل أولاً (قاعدة
بيانات + تثبيت + تسجيل دخول وطلب خدمة فعلي)، ثم إضافة بقية الميزات دفعة
دفعة في جولات قادمة.

## التثبيت

1. عدّل `config.php` وضع بيانات MySQL الحقيقية (الاسم/المستخدم/كلمة المرور).
2. شغّل من الترمنال:
   ```bash
   php install.php
   ```
   يتحقق السكربت من وجود `sql/schema.sql`، ينشئ قاعدة البيانات إذا لم تكن
   موجودة، ويستورد كل الجداول (25 جدول) + بيانات أولية (مستويات، مزوّد
   افتراضي، طرق دفع، حساب أدمن وحساب تجربة). يمكن إعادة تشغيله بأمان دون
   تكرار البيانات.
3. بعد نجاح التثبيت **احذف `install.php` من السيرفر** لأسباب أمنية.
4. عدّل مفتاح/رابط المزوّد الحقيقي من لوحة الإدارة (`/admin/index.php`)
   بدل القيمة الوهمية المزروعة بالبذور.
5. سجّل دخول كأدمن: `admin@admin.com` / `2sebvWFr6BYwVBrV` — **غيّر كلمة
   المرور هذه فوراً**، هي نفسها الموجودة بالنسخة الأصلية وأصبحت معروفة.

## بنية المجلد

```
php/
  config.php          بيانات الاتصال بقاعدة البيانات (حدّثها بسيرفرك)
  install.php         يستورد sql/schema.sql (احذفه بعد أول تشغيل)
  sql/schema.sql       الشيما الكاملة + بيانات أولية
  includes/db.php      اتصال PDO واحد مشترك
  includes/functions.php  جلسات، إعدادات، تسجيل دخول/أدمن
  includes/smm.php     التواصل مع API مزوّد SMM (جلب خدمات + تنفيذ طلب)
  index.php / login.php / register.php / logout.php
  dashboard.php        لوحة المستخدم: الرصيد + كتالوج الخدمات + طلب + طلباتي
  api/order.php        استلام نموذج الطلب وتنفيذه
  api/services.php     كتالوج الخدمات بصيغة JSON
  admin/index.php      إحصائيات + تعديل إعدادات المزوّد الافتراضي
```

## ما تم اختباره فعلياً (ليس افتراضاً)

تم تثبيت MySQL/PHP محلياً هنا واختبار التدفق الكامل حقيقةً قبل التسليم:
استيراد الشيما (وإعادة تشغيله للتأكد من عدم تكرار البيانات)، تسجيل
دخول/خروج، عرض كتالوج خدمات من مزوّد تجريبي، تنفيذ طلب ناجح (خصم الرصيد
+ تسجيل الطلب بالحالة الصحيحة)، تنفيذ طلب يرفضه المزوّد (استرجاع الرصيد
المخصوم تلقائياً)، ولوحة إدارة بإحصائيات صحيحة مع منع غير الأدمن منها (403).

## ما هو متوفر بالبنية التحتية للجداول، لكن بلا واجهة PHP بعد

جداول الدعم الفني، المحادثات مع المساعد الذكي، الإشعارات، الإعلانات،
الإحالة (referrals)، الكوبونات، المفضّلة، الخدمات المخصّصة، التقييمات،
ونظام المستويات/الخصومات — كل جداولها جاهزة بـ `schema.sql` منذ الآن
(لا حاجة لتعديل الشيما لاحقاً)، لكن صفحات PHP لاستخدامها ستُضاف بجولات
قادمة، وبالترتيب حسب الأهمية.

## غير مُنجز بعد (جولات قادمة)

- شحن المحفظة (Binance Pay / آسياسيل / Telegram Stars) والدفع اليدوي.
- المساعد الذكي (AI chat).
- تعدد مزوّدي SMM (الكود الحالي يدعم مزوّد افتراضي واحد فقط).
- الدعم الفني، الإشعارات، نظام الإحالة، الكوبونات، المفضّلة، التقييمات.
- لوحة إدارة كاملة (مستخدمين، طلبات، فلاتر خدمات، إعدادات الموقع، إلخ).
- واجهة الصفحة الرئيسية التسويقية (Landing page).
