# نظام إدارة شركة الصوى للصرافة

نظام PHP + MySQL لإدارة الفروع والموظفين والحضور والرواتب والطلبات، بثلاث لوحات تحكم حسب الصلاحية. **4 ملفات فقط**، كل ملف مستقل بالكامل (لا يعتمد على أي ملف آخر سوى `config.php` الذي يُنشأ تلقائياً):

| الملف | الوظيفة |
|---|---|
| `install.php` | المثبّت التلقائي: ينشئ قاعدة البيانات والجداول، ويكتب `config.php` |
| `hr.php` | لوحة الموارد البشرية (HR) — يدير كل الفروع وكل الموظفين في أي فرع، الطلبات، الرواتب، سعر الصرف، الإعدادات |
| `branch.php` | لوحة مدير الفرع — يدير موظفي فرعه فقط، الحضور، طلبات موظفيه، الإيجاز اليومي |
| `employee.php` | نافذة الموظف — حضور/انصراف ذاتي، تقديم طلبات، عرض الراتب والملف الوظيفي |

كل ملف من الثلاثة (`hr.php` / `branch.php` / `employee.php`) يحتوي **شاشة تسجيل دخول خاصة به** مدمجة فيه — لا يوجد ملف `login.php` منفصل. كل ملف مقسّم داخلياً بوضوح إلى: منطق PHP بالكامل في الأعلى، ثم واجهة HTML/CSS (مع تصميم RTL مدمج بالكامل، بلا ملفات تصميم خارجية) بعد التعليق `الواجهة`.

## التثبيت على الاستضافة (cPanel / Hostinger وغيرها)

1. ارفع الملفات الأربعة (`install.php`, `hr.php`, `branch.php`, `employee.php`) إلى مجلد `public_html` (أو المجلد الفرعي الذي تريده) عبر File Manager أو FTP.
2. تأكد من أن المجلد قابل للكتابة (المثبّت سينشئ ملف `config.php` بجانبها تلقائياً).
3. أنشئ قاعدة بيانات MySQL فارغة ومستخدماً لها من لوحة تحكم الاستضافة (cPanel → MySQL Databases)، واربط المستخدم بالقاعدة بكل الصلاحيات.
4. افتح `https://your-domain.com/install.php` من المتصفح.
5. أدخل بيانات الاتصال بقاعدة البيانات (Host غالباً `localhost`)، وبيانات حساب مدير الموارد البشرية الأول (بريد إلكتروني وكلمة مرور).
6. اضغط **تثبيت النظام الآن** — سيتم تلقائياً:
   - الاتصال بقاعدة البيانات والتحقق منه.
   - إنشاء جميع الجداول (`CREATE TABLE IF NOT EXISTS`) إن لم تكن موجودة.
   - إدراج بيانات أساسية: فرع افتراضي، إعدادات الشركة، وحساب HR الأول.
   - كتابة `config.php` تلقائياً ببيانات الاتصال.
7. بعد نجاح التثبيت، افتح `hr.php` وسجّل الدخول بالبريد وكلمة المرور اللذين أدخلتهما.

> **مهم — الأمان:** ملف `config.php` يحتوي بيانات اتصال قاعدة البيانات الحقيقية، ولذلك هو مُستثنى من Git عمداً (`.gitignore`). لا تضف بيانات اتصال حقيقية إلى الكود المصدري أو تدفعها إلى مستودع عام؛ ينشئه المثبّت مباشرة على السيرفر فقط. لإعادة التثبيت، احذف `config.php` من السيرفر أولاً.

## إنشاء الحسابات

- **HR**: يُنشأ تلقائياً أثناء التثبيت (بريد إلكتروني + كلمة مرور)، ويسجّل الدخول من `hr.php`.
- **مدير فرع / موظف**: يُنشأ من داخل `hr.php` (تبويب "الموظفون") أو من `branch.php` (تبويب "موظفو الفرع") عند إضافة موظف جديد مع تعبئة حقل "كلمة مرور حساب الدخول". اسم المستخدم هو رقم التوظيف الذي يولّده النظام تلقائياً (يبدأ من 1001). يسجّل مدير الفرع الدخول من `branch.php`، والموظف من `employee.php`.

## الصلاحيات بين الأدوار

- **HR** يرى ويدير كل الفروع وكل الموظفين، ويراجع كل الطلبات من أي فرع.
- **مدير الفرع** يرى ويدير فقط موظفي فرعه، وطلباتهم، وسجل الحضور والإيجاز اليومي لفرعه.
- **الموظف** يرى بياناته الخاصة فقط (حضوره، طلباته، راتبه)، ويشاهد الإيجاز اليومي لفرعه للاطلاع فقط دون تعديل.

كل ملف من الثلاثة يستخدم مفتاح جلسة منفصل (`hr_user` / `branch_user` / `employee_user`)، لذلك تسجيل الدخول في أحدها لا يمنح أي صلاحية في الآخرين تلقائياً — الوصول لملف بدون تسجيل دخول صحيح لذلك الدور يعرض شاشة الدخول فقط.

## تسجيل الخروج

كل ملف يدعم تسجيل الخروج عبر إضافة `?logout=1` لرابطه، مثال: `hr.php?logout=1`.
