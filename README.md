# نظام إدارة شركة الصوى للصرافة

نظام PHP + MySQL لإدارة الفروع والموظفين والحضور والرواتب والطلبات، بثلاث لوحات تحكم حسب الصلاحية. **4 ملفات فقط**، كل ملف مستقل بالكامل (لا يعتمد على أي ملف آخر سوى `config.php` الذي يُنشأ تلقائياً):

| الملف | الوظيفة |
|---|---|
| `install.php` | المثبّت التلقائي: ينشئ قاعدة البيانات والجداول، ويكتب `config.php` |
| `hr.php` | لوحة الموارد البشرية (HR) — يدير كل الفروع وكل الموظفين في أي فرع، الطلبات، الرواتب، سعر الصرف، الإعدادات |
| `branch.php` | لوحة مدير الفرع — يدير موظفي فرعه فقط، الحضور، طلبات موظفيه، الإيجاز اليومي |
| `index.php` | نافذة الموظف — الصفحة الرئيسية للموقع (حضور/انصراف ذاتي، تقديم طلبات، عرض الراتب والملف الوظيفي) |

كل ملف من الثلاثة (`hr.php` / `branch.php` / `index.php`) يحتوي **شاشة تسجيل دخول خاصة به** مدمجة فيه — لا يوجد ملف `login.php` منفصل. كل ملف مقسّم داخلياً بوضوح إلى: منطق PHP بالكامل في الأعلى، ثم واجهة HTML/CSS (مع تصميم RTL مدمج بالكامل، بلا ملفات تصميم خارجية) بعد التعليق `الواجهة`.

## التثبيت على الاستضافة (cPanel / Hostinger وغيرها)

1. ارفع الملفات الستة (`install.php`, `hr.php`, `branch.php`, `index.php`, `general.php`, `migrate.php`) وملف `.htaccess` إلى مجلد `public_html` (أو المجلد الفرعي الذي تريده) عبر File Manager أو FTP.
2. تأكد من أن المجلد قابل للكتابة (المثبّت سينشئ ملف `config.php` بجانبها تلقائياً).
3. أنشئ قاعدة بيانات MySQL فارغة ومستخدماً لها من لوحة تحكم الاستضافة (cPanel → MySQL Databases)، واربط المستخدم بالقاعدة بكل الصلاحيات.
4. افتح `https://your-domain.com/install.php` من المتصفح.
5. أدخل بيانات الاتصال بقاعدة البيانات (Host غالباً `localhost`)، وبيانات حساب مدير الموارد البشرية الأول ثم المسؤول العام (بريد إلكتروني وكلمة مرور لكل منهما).
6. اضغط **تثبيت النظام الآن** — سيتم تلقائياً:
   - الاتصال بقاعدة البيانات والتحقق منه.
   - إنشاء جميع الجداول (`CREATE TABLE IF NOT EXISTS`) إن لم تكن موجودة.
   - إدراج بيانات أساسية: فرع افتراضي، إعدادات الشركة، وحساب HR والمسؤول العام الأولين.
   - كتابة `config.php` تلقائياً ببيانات الاتصال.
7. بعد نجاح التثبيت، افتح `/hr` وسجّل الدخول بالبريد وكلمة المرور اللذين أدخلتهما.

### روابط نظيفة بدون امتداد .php

ملف `.htaccess` المرفق (Apache + `mod_rewrite`، متوفر افتراضياً على معظم استضافات cPanel) يفعّل روابط قصيرة تلقائياً — ارفعه مع باقي الملفات إلى نفس المجلد:

| الرابط | يفتح |
|---|---|
| `/` (الصفحة الرئيسية) | `index.php` — نافذة الموظف |
| `/hr` | `hr.php` |
| `/branch` | `branch.php` |
| `/general` | `general.php` |
| `/migrate` | `migrate.php` |
| `/install` | `install.php` |

الوصول المباشر بامتداد `.php` (مثل `/hr.php`) يبقى يعمل أيضاً كما هو.

> **مهم — الأمان:** ملف `config.php` يحتوي بيانات اتصال قاعدة البيانات الحقيقية، ولذلك هو مُستثنى من Git عمداً (`.gitignore`). لا تضف بيانات اتصال حقيقية إلى الكود المصدري أو تدفعها إلى مستودع عام؛ ينشئه المثبّت مباشرة على السيرفر فقط. لإعادة التثبيت، احذف `config.php` من السيرفر أولاً.

## إنشاء الحسابات

- **HR**: يُنشأ تلقائياً أثناء التثبيت (بريد إلكتروني + كلمة مرور)، ويسجّل الدخول من `hr.php`.
- **مدير فرع / موظف**: يُنشأ من داخل `hr.php` (تبويب "الموظفون") أو من `branch.php` (تبويب "موظفو الفرع") عند إضافة موظف جديد مع تعبئة حقل "كلمة مرور حساب الدخول". اسم المستخدم هو رقم التوظيف الذي يولّده النظام تلقائياً (يبدأ من 1001). يسجّل مدير الفرع الدخول من `branch.php`، والموظف من `index.php`.

## الصلاحيات بين الأدوار

- **HR** يرى ويدير كل الفروع وكل الموظفين، ويراجع كل الطلبات من أي فرع، ويولّد التقارير.
- **مدير الفرع** يرى ويدير فقط موظفي فرعه، وطلباتهم، وسجل الحضور والإيجاز اليومي لفرعه، ويفوّض أحد موظفيه لكتابة الإيجاز نيابة عنه.
- **الموظف** يرى بياناته الخاصة فقط (حضوره، طلباته، راتبه)، ويشاهد الإيجاز اليومي لفرعه للاطلاع فقط — إلا إذا كان مفوَّضاً حالياً من مدير الفرع، فتُفتح له صلاحية الإضافة تلقائياً.

كل ملف يستخدم مفتاح جلسة منفصل (`hr_user` / `branch_user` / `employee_user` / `gm_user`)، لذلك تسجيل الدخول في أحدها لا يمنح أي صلاحية في الآخرين تلقائياً — الوصول لملف بدون تسجيل دخول صحيح لذلك الدور يعرض شاشة الدخول فقط.

## تسجيل الخروج

كل ملف يدعم تسجيل الخروج عبر إضافة `?logout=1` لرابطه، مثال: `/hr?logout=1`.

## التصميم

تصميم فاتح (Light) بألوان تركوازية/ذهبية (`#006b73` / `#c99a3d`) وخط IBM Plex Sans Arabic، مطابق لتصميم النماذج الأصلية. لوحة `hr.php` بتخطيط قائمة جانبية لسطح المكتب، بينما `branch.php` و`index.php` يضيفان أيضاً شريط تنقّل سفلي (Bottom Navigation) يظهر تلقائياً على الشاشات الصغيرة (الجوال).

## ميزات إضافية

- **رفع الملفات**: صورة شخصية ومستمسك لكل موظف (من `hr.php` أو `branch.php`)، ومرفق اختياري لكل قيد في الإيجاز اليومي. تُحفظ في `uploads/photos` و`uploads/documents` و`uploads/ledger` (يُنشئها المثبّت تلقائياً، وهي مستثناة من Git).
- **التفويضات** (`branch.php`): يفوّض مدير الفرع أحد موظفيه لكتابة الإيجاز اليومي خلال فترة غيابه؛ الموظف المفوَّض يرى زر الإضافة يظهر تلقائياً في `index.php` أثناء فترة التفويض فقط.
- **لائحة الشرف** (`index.php`): أفضل 3 موظفين حسب نسبة الالتزام هذا الشهر، تظهر في الصفحة الرئيسية لكل موظف.
- **التقارير** (`hr.php`): تقرير الحضور / الرواتب / الإجازات والطلبات / تقرير شامل للإيجاز اليومي، بفلترة حسب التاريخ والفرع، مع تحميل النتائج كملف CSV.
