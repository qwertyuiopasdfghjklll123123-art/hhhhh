# واصل — نسخة PHP + MySQL (مرحلة أولى)

نسخة من منصة واصل (الأصل بـ `webapp.py`/Flask/SQLite) مبنية بـ PHP 8 + MySQL لتعمل على
استضافة مشتركة (cPanel/DirectAdmin/Hostinger) **بدون VPS** - بدون Selenium ولا متصفح
خلفي، كل شيء طلب PHP عادي + قاعدة MySQL.

هذه **مرحلة أولى**: الأساس (قاعدة البيانات + الجلسات + الحماية + تسجيل الدخول) جاهز
ومُختبَر فعلياً (تشغيل حقيقي عبر خادم PHP + MySQL حقيقيين، لا محاكاة)، أما الحسابات/الحملات/
الاشتراكات/لوحة الأدمن/الواجهة فمحجوزة للمرحلة القادمة - راجع «الناقص حالياً» أسفل الصفحة.

## البنية

```
php/
├─ .htaccess            ← يوجّه لـ public/ ويحجب core/ data/ sql/ tools/
├─ public/              ← نقطة الدخول (index.php)
├─ core/
│  ├─ config.sample.php ← انسخه إلى config.php واكتب بياناتك (الملف الوحيد الذي تعدّله)
│  ├─ bootstrap.php
│  ├─ lib/              ← قاعدة البيانات، الجلسات، الحماية، التوجيه، مزوّد واتساب...
│  └─ routes/           ← مسارات الموقع (auth.php حالياً، والباقي قادم)
├─ sql/database.sql     ← قاعدة البيانات كاملة (9 جداول) بملف واحد
├─ tools/               ← init_db.php, create_admin.php
└─ data/                ← يكتب فيه الموقع (سجلات/كاش) - لا يُخدَم من الويب
```

## التثبيت

1. ارفع محتوى `php/` إلى `public_html` (أو مجلد الدومين) وفكّه مباشرة هناك.
2. أنشئ قاعدة MySQL ومستخدماً لها بكل الصلاحيات، واستورد `sql/database.sql` من phpMyAdmin
   (Import)، أو عبر: `php tools/init_db.php` (يحتاج `core/config.php` معبّى أولاً).
3. انسخ `core/config.sample.php` إلى `core/config.php` واكتب بياناتك (قاعدة البيانات،
   `SECRET_KEY`، `ADMIN_EMAIL`/`ADMIN_PASSWORD`). أول زيارة للموقع تنشئ حساب الأدمن تلقائياً.
4. (اختياري الآن) `GOOGLE_CLIENT_ID` لتفعيل زر «الدخول بجوجل»، و`WA_PROVIDER_DRIVER` لتفعيل
   إرسال رموز واتساب - راجع `core/lib/wa_provider.php`.

## جاهز ومُختبَر فعلياً بهذه المرحلة

* قاعدة البيانات الكاملة (9 جداول MySQL تطابق جداول `webapp.py`).
* تسجيل الدخول/الخروج: بريد+كلمة مرور (bcrypt)، حساب مدير ثابت احتياطي (اختياري من
  `config.php`، غير مفعّل افتراضياً)، ومسارات الدخول بواتساب (`/auth/whatsapp/*`) وجوجل
  (`/api/google-login`) جاهزة بنيوياً بانتظار تفعيل مزوّد واتساب حقيقي.
* الجلسة: موقّعة بكوكي (متوافقة حرفياً مع كوكي جلسة Flask لو استعملت نفس `SECRET_KEY` -
  يبقى المستخدمون مسجّلين الدخول بعد النقل من بايثون بلا إعادة تسجيل)، مدتها **30 يوماً**
  بطلب صاحب المنصة (كانت تطلب «جلسة لا تنتهي» - 30 يوماً بديل عملي وأأمن من بلا انتهاء).
* حماية: CSRF (يرفض الطلبات المغيّرة من موقع آخر)، bcrypt لكل كلمات المرور، إيقاف تخمين
  كلمة المرور/الرموز بعد محاولات فاشلة، سجل تدقيق لعمليات لوحة الأدمن، ترويسات أمان،
  قائمة IP بيضاء اختيارية للوحة الأدمن، حماية SQL injection (استعلامات مُجهّزة فقط).
* حساب المدير الثابت الخطير (كان مكتوباً بالكود المصدري بنسخة بايثون) صار اختيارياً من
  `config.php` فقط، فاضياً/معطّلاً افتراضياً.

## الناقص حالياً (المرحلة القادمة)

* **حسابات واتساب (الاتصال الفعلي بالمزوّد) + الحملات + الرد الآلي.** الأهم: `webapp.py`
  يرسل عبر متصفح Chrome حقيقي (Selenium) - وهذا **غير ممكن على استضافة مشتركة إطلاقاً**
  (لا صلاحية تشغيل متصفح، ولا عمليات خلفية دائمة). البديل الجاهز بنيوياً (`wa_provider.php`)
  يرسل عبر مزوّد واتساب خارجي (API) بدلاً من متصفح - يحتاج منك تختار مزوّداً وتعطيني بياناته:
  - **Meta WhatsApp Cloud API** (الرسمي): يحتاج حساب Meta for Developers + رقم أعمال.
  - **أي مزوّد "واتساب غير رسمي"** يتيح ربط رقمك الشخصي بمسح QR من لوحته (نفس تجربتك
    القديمة بالضبط، بدون VPS من طرفك) - أرسل لي اسمه وبياناته وأربطه بـ `http_generic`.
* مفاتيح API الخارجية (`/api/v1/send`)، المشتركين (CRM)، الاشتراكات/الدفع، لوحة الأدمن
  (الإعدادات/الشعار/العملاء)، صفحة `/app` (الواجهة) بتصميم مأخوذ من ملف الـ zip المرجعي.
* نقل بيانات حقيقية من قاعدة SQLite القديمة (أداة هجرة لم تُبنَ بعد).
