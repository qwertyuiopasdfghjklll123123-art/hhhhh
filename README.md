# واصل — منصة حملات واتساب متعددة الفروع (PHP لاستضافة cPanel)

منصة لإدارة حملات واتساب لعدة فروع، تشتغل على **استضافة cPanel عادية (PHP + MySQL)**
بدون VPS، **بدون تثبيت أي برنامج أو إضافة**، وبدون أي اشتراك أو خدمة خارجية.

## كيف يشتغل الإرسال

الفرع يفتح الحملة من **الجوال أو الكمبيوتر** ويضغط **"إرسال عبر واتساب"**:

1. ينفتح واتساب ومحادثة الرقم والرسالة (النص + الرابط) مكتوبة جاهزة.
2. يضغط إرسال بواتساب، ويرجع للموقع.
3. الموقع يكون جهّز الرقم الجاي تلقائياً — وهكذا لحد ما تخلص رسائل اليوم.

- على **الجوال** ينفتح تطبيق واتساب مباشرة.
- على **الكمبيوتر** ينفتح واتساب ويب بنفس التبويب كل مرة (تضغط Enter هناك للإرسال)،
  أو تطبيق واتساب للكمبيوتر إذا اخترته من "طريقة فتح واتساب".
- **مهلة بين رقم والثاني** (10 ثواني افتراضياً) تحمي الرقم من الحظر.
- إذا اثنين من الفرع يرسلون نفس الحملة سوا من جهازين، كل جهاز ياخذ رقم مختلف — ما ينرسل
  نفس الرقم مرتين.
- لكل رقم: **"الرقم ما عنده واتساب"** و**"تخطي"**، ولآخر رقم: **"تراجع"**.

ليش مو تلقائي 100%؟ استضافة cPanel ما تقدر تفتح واتساب بنفسها، وواتساب ما عنده طريقة
مجانية للإرسال الآلي — الإرسال التلقائي الكامل يحتاج سيرفر خاص (VPS) أو خدمة API مدفوعة
أو برنامج مثبّت على جهاز. الإرسال بالضغط يتجنب كل هذا.

## المزايا

- **أدمن واحد ثابت بالكود** (بريد وكلمة مرور بملف `inc/core.php`) — ما فيه تسجيل حساب من الموقع.
- **الأدمن فقط ينشئ الفروع**: اسم + بريد + كلمة مرور (أو مولّدة تلقائياً)، ويقدر يغيّر كلمة مرور
  أي فرع (يطلع من كل أجهزته) أو يحذفه.
- **صلاحيات الفرع**: حسابات واتساب، الحملات، والإشعارات فقط — وبياناته معزولة عن باقي الفروع.
- **حملات نصية**: حقل للنص وحقل للرابط (يُضاف بآخر الرسالة)، بدون مرفقات صور/ملفات.
- **الأرقام** تُكتب أو تُرفع من Excel (.xlsx) أو CSV — يتعرّف على عمود الأرقام تلقائياً،
  ويحذف المكرر والناقص، ويقبل الأرقام العربية (٠٧٧٠…).
- **رمز الدولة**: قائمة أعلى حقل الأرقام (العراق 964 افتراضياً) — اكتب الأرقام محلياً
  (07701234567) والرمز ينضاف تلقائياً. الرقم المكتوب دولياً (+971…) يبقى كما هو.
- **الجدولة**: فوري، أو بموعد واحد، أو **تقسيم على أيام** (مثلاً 80 رقم ← 20 يومياً على
  4 أيام). كل يوم بموعده يوصل إشعار "جاهزة للإرسال" وتنفتح أرقامه للإرسال.
- **متابعة**: تقدّم كل حملة، جدول الأيام، الأرقام اللي ما عندها واتساب، وإلغاء يوم أو حملة.
- **إشعارات** داخل الموقع وبالمتصفح (حان موعد الحملة، خلصت رسائل اليوم، اكتملت الحملة…).
- **لوحة الأدمن**: إحصائيات كل الفروع، ترتيب الفروع حسب نسبة النجاح، تغيير اسم وشعار الموقع.
- **تطبيق PWA** يتثبّت على الجوال والكمبيوتر، وتصميم لسطح المكتب (شريط جانبي) يتحول لقائمة على الجوال.

## التثبيت على cPanel (مرة وحدة)

1. **ارفع الملفات**: cPanel ← File Manager ← `public_html` (أو مجلد فرعي) ← Upload لملف
   الـ zip ← Extract. لازم يكون `index.php` مباشرة داخل المجلد.
2. **أنشئ قاعدة بيانات**: cPanel ← MySQL Databases:
   - أنشئ قاعدة بيانات (مثلاً `user_wasel`) ومستخدم بكلمة مرور.
   - Add User To Database ← اختر ALL PRIVILEGES.
3. **افتح المثبّت**: `https://دومينك/install.php` ← أدخل بيانات قاعدة البيانات (السيرفر
   غالباً `localhost`) ← "تثبيت النظام الآن".
4. **احذف `install.php`** من مدير الملفات بعد نجاح التثبيت (للأمان).
5. **ادخل بحساب الأدمن** من `https://دومينك/`.

المتطلبات: PHP 7.4 أو أحدث (يُفضّل 8.1+) مع إضافة `pdo_mysql`. ويُفضّل تفعيل `zip`
(لقراءة Excel) و`gd` و`mbstring` من cPanel ← Select PHP Version ← Extensions (المثبّت
يفحصها لك). فعّل شهادة SSL المجانية (AutoSSL) حتى يشتغل الموقع على `https`.

**تحديث نسخة سابقة**: ارفع الملفات الجديدة فوق القديمة (بدون حذف `config.php` ومجلد
`uploads`) — قاعدة البيانات تتحدّث تلقائياً أول ما تفتح الموقع، وكل البيانات تبقى.

## الاستخدام اليومي للفرع

1. **حسابي** ← "إضافة حساب": اسم للرقم اللي ترسل منه ورقمه (مرة وحدة).
2. **الحملات** ← حملة جديدة: الأرقام، النص، الرابط، والتوقيت ← "حفظ الحملة".
3. اضغط **"إرسال"** على الحملة (أو من بطاقة "جاهزة للإرسال الآن" أعلى الصفحة) وكمّل رقم رقم.

### من الجوال (بدون تحميل أي شي)

- افتح رابط الموقع بمتصفح الجوال الموجود أصلاً (كروم أو سفاري) وسجّل الدخول مع **"تذكرني"**
  — يبقى داخل 30 يوم، فما يحتاج يكتب كلمة المرور كل يوم.
- زر "إرسال عبر واتساب" يفتح **تطبيق واتساب الموجود بالجوال** والرسالة جاهزة.
- على أندرويد يظهر زر **"اختيار أرقام من جهات اتصال الجوال"** لإضافة أرقام الحملة من الأسماء المحفوظة.
- شريط "أضف أيقونة الموقع للشاشة الرئيسية" **اختياري** — إذا ما تريده اضغط ×.

## بيانات دخول الأدمن

موجودة أعلى ملف `inc/core.php`:

```php
define('ADMIN_EMAIL', 'fastcrand@gmail.com');
define('ADMIN_PASSWORD', 'fastcrand1');
```

لتغييرها عدّل السطرين وارفع الملف من جديد. لا تشارك هذا الملف ولا تخلّي المستودع عام.

## ملفات المشروع

| الملف/المجلد | الوظيفة |
|---|---|
| `index.php` | الموقع: شاشة الدخول، لوحة التحكم، وواجهة JSON (`?api=`) |
| `install.php` | المثبّت: ينشئ الجداول ويكتب `config.php` |
| `inc/` | منطق النظام (قاعدة البيانات، الحملات، الإرسال، الصلاحيات) — محمي من المتصفح |
| `assets/` | التصميم والواجهة والخطوط والأيقونات (كلها محلية بدون مواقع خارجية) |
| `uploads/` | شعار الموقع المرفوع |
| `config.php` | بيانات قاعدة البيانات — ينشئه المثبّت على السيرفر فقط (مستثنى من Git) |

## أسئلة شائعة

- **الزر يفتح واتساب ويب بس أريد تطبيق الكمبيوتر**: بشاشة الإرسال ← "نص الرسالة وطريقة فتح
  واتساب" ← اختر "تطبيق واتساب على الجهاز".
- **على الجوال ما ينفتح التطبيق**: جرّب "رابط wa.me" أو "تطبيق واتساب" من نفس القائمة.
- **ضغطت إرسال بالغلط أو الرقم طلع ما عنده واتساب**: سطر "آخر رقم" تحت الزر فيه "تراجع"
  و"الرقم ما عنده واتساب" (خلال نص ساعة).
- **ما وصلني إشعار موعد اليوم الجديد**: الإشعارات تظهر لما يكون الموقع مفتوح (أو مثبّت كتطبيق
  وفيه إشعارات مفعّلة). الأرقام نفسها تجهز بموعدها حتى لو ما شفت الإشعار.

## ملاحظة مهمة

حتى مع الإرسال اليدوي، إرسال رسائل كثيرة لأرقام ما تعرفك يمكن يسبب حظر الرقم من واتساب.
أرسل لعملائك اللي وافقوا يستلمون رسائلك، وخلّي مهلة 10 ثواني أو أكثر، ووزّع القوائم الكبيرة على أيام.
