# لوحة إدارة المشاريع الذكية

نظام لوحة تحكم وإدارة مشاريع بلغة PHP الخام (بدون أي إطار عمل خارجي) وقاعدة
بيانات MySQL، بتثبيت تلقائي كامل، إدارة مستخدمين وصلاحيات، وقسم "معرفة
المشروع" يربط كل مشروع بهيكل قاعدة بياناته وقواعده البرمجية ومستودع GitHub
الخاص به، مع مساعد ذكي (نص ورؤية) يمكن ربطه بأكثر من مزوّد ذكاء اصطناعي في نفس
الوقت (عدة مفاتيح NVIDIA NIM، أو أي مزوّد آخر متوافق مع بنية OpenAI Chat
Completions API مثل OpenAI وGroq وDeepSeek)، ويستخدم سياق المشروع المحفوظ
تلقائياً في كل طلب.

الواجهة مبنية بتصميم أسود بالكامل بأسلوب شبيه بـ Claude: قائمة جانبية ثابتة +
لوحة محتوى رئيسية، وداخل المساعد الذكي رواق محادثات + لوحة دردشة (تقسيم شاشة
من مستويين)، مع أزرار ملوّنة لكل إجراء (أساسي/نجاح/خطر/تحذير)، وخط IBM Plex
Sans Arabic، ودعم كامل لـ RTL ولشاشات الكمبيوتر المحمول والهواتف.

## المتطلبات

- PHP 8.1+ مع امتدادات: `pdo_mysql`, `curl`, `openssl`, `json` (مفعّلة افتراضياً في أغلب الاستضافات)
- MySQL 5.7+ أو MariaDB 10.3+
- خادم Apache (مرفق ملفات `.htaccess` جاهزة) أو Nginx/PHP-FPM
- لا حاجة لـ Composer أو أي حزم Node — المشروع PHP خام بالكامل

## التثبيت

1. ارفع محتويات المشروع إلى السيرفر (أو استنسخه داخل مجلد الاستضافة).
2. تأكد أن مجلد `config/` قابل للكتابة من قبل خادم الويب (سيُنشئ فيه المثبّت ملف `config.php`).
3. افتح المشروع من المتصفح — إن لم يوجد `config/config.php` سيتم توجيهك تلقائياً إلى `install.php`.
4. أدخل بيانات الاتصال بقاعدة البيانات (Host, Port, Name, User, Password). إن لم تكن قاعدة البيانات موجودة سيتم إنشاؤها تلقائياً (أو استخدام الموجودة إن لم تسمح صلاحيات المستخدم بإنشائها، كما هو الحال في بعض الاستضافات المشتركة).
5. أدخل بيانات حساب المسؤول الرئيسي (Admin): الاسم، البريد الإلكتروني، كلمة المرور.
6. عند الضغط على "ابدأ التثبيت" يقوم النظام بـ:
   - إنشاء/استخدام قاعدة البيانات وتنفيذ `database/schema.sql` بالكامل (كل الجداول بصيغة `IF NOT EXISTS`).
   - إنشاء حساب المسؤول بكلمة مرور مشفّرة (`password_hash` بخوارزمية BCRYPT).
   - توليد مفتاح تشفير عشوائي (32 بايت) وكتابة `config/config.php` تلقائياً.
7. سيتم توجيهك لصفحة تسجيل الدخول. سجّل الدخول بحساب المسؤول وابدأ العمل.

> لإعادة التثبيت من الصفر، احذف ملف `config/config.php` يدوياً من السيرفر.

### التثبيت اليدوي (اختياري)

يمكن نسخ `config/config.sample.php` إلى `config/config.php` وتعديله يدوياً، مع
استيراد `database/schema.sql` وإنشاء مستخدم مسؤول يدوياً عبر SQL باستخدام
`password_hash()` في PHP لتوليد كلمة المرور.

## هيكل المشروع

```
├── install.php              # معالج التثبيت التلقائي (قاعدة البيانات + حساب الأدمن)
├── index.php                 # موجّه الدخول (يحوّل لتسجيل الدخول أو لوحة التحكم)
├── login.php / logout.php    # تسجيل الدخول/الخروج بجلسات آمنة
├── dashboard.php              # نظرة عامة: إحصائيات، أحدث المشاريع، آخر النشاطات
├── users.php                  # إدارة المستخدمين (للمسؤول فقط): إنشاء/تعطيل/أدوار
├── profile.php                 # الحساب الشخصي وتغيير كلمة المرور
├── projects.php                # قائمة المشاريع (إنشاء/أرشفة/حذف)
├── project_context.php         # صفحة المشروع: تبويب "المساعد الذكي" وتبويب "السياق والإعدادات"
├── config/
│   ├── config.sample.php       # قالب مرجعي (config.php الفعلي يُنشأ تلقائياً وغير موجود بالمستودع)
│   └── .htaccess                # يمنع الوصول المباشر للمجلد بالكامل
├── database/
│   └── schema.sql               # هيكل قاعدة البيانات الكامل (idempotent)
├── includes/
│   ├── functions.php            # أدوات عامة: CSRF، الجلسات الآمنة، رسائل Flash، ترويسات الأمان
│   ├── db.php                    # اتصال PDO وحيد (Singleton) — Prepared Statements فقط
│   ├── crypto.php                 # تشفير/فك تشفير AES-256-GCM لأسرار كل مشروع
│   ├── auth.php                    # تسجيل الدخول، الحماية من هجمات التخمين، الصلاحيات
│   └── layout_start.php / layout_end.php  # القالب المشترك (القائمة الجانبية + المحتوى)
├── services/
│   ├── AiClient.php                # عميل ذكاء اصطناعي عام (نص + رؤية) متوافق مع أي مزوّد OpenAI-style، وبناء موجّه النظام
│   └── GithubClient.php             # عميل GitHub REST API (قراءة ملفات + إنشاء Commits)
├── api/                               # نقاط AJAX (JSON) خلف نفس نظام الجلسات و CSRF
│   ├── conversations.php               # قائمة/حذف/إعادة تسمية محادثات المساعد الذكي
│   ├── messages.php                     # إرسال رسالة للمساعد الذكي (يحقن السياق تلقائياً) وسجل الرسائل
│   ├── github_file.php                   # تصفح/قراءة ملفات المستودع
│   └── github_commit.php                  # رفع تعديل (Commit) إلى المستودع
└── assets/
    ├── css/style.css                       # نظام التصميم الأسود الكامل
    └── js/app.js                            # كل تفاعلات الواجهة (بدون أي مكتبات خارجية)
```

## معايير الأمان المطبّقة

- **PDO + Prepared Statements حصراً** في كل استعلام بقاعدة البيانات (`ATTR_EMULATE_PREPARES = false`) — لا استعلامات مُركَّبة من نصوص خام.
- **كلمات المرور**: `password_hash()` بخوارزمية BCRYPT، ومقارنة بـ `password_verify()`.
- **حماية CSRF**: رمز عشوائي 32 بايت لكل جلسة، يُتحقق منه في كل نموذج POST وكل طلب AJAX عبر ترويسة `X-CSRF-Token`.
- **حماية XSS**: تنظيف كل المخرجات عبر `htmlspecialchars()` (دالة `e()`)، وواجهة المساعد الذكي تبني عناصر DOM عبر `textContent` حصراً بدل `innerHTML` لأي نص قادم من المستخدم أو من رد النموذج الذكي.
- **جلسات آمنة**: أسماء جلسة مخصّصة، `HttpOnly` + `SameSite=Lax` + `Secure` عند HTTPS، `session_regenerate_id()` عند تسجيل الدخول، ومهلة خمول تلقائية.
- **الحماية من هجمات التخمين (Brute-force)**: قفل مؤقت بعد 5 محاولات فاشلة لكل مزيج (IP + بريد إلكتروني).
- **تشفير الأسرار في قاعدة البيانات**: GitHub Personal Access Token ومفاتيح كل مزوّدي الذكاء الاصطناعي (`ai_providers.api_key`) تُخزَّن مشفّرة (AES-256-GCM) بمفتاح مولَّد تلقائياً أثناء التثبيت ومحفوظ في `config/config.php` فقط (خارج المستودع). القيم المشفّرة **لا تُفَكّ ولا تُعرض للمتصفح إطلاقاً** بعد الحفظ — الحقول تظهر فارغة مع إشعار "محفوظ".
- **مفاتيح الـ API لا تصل للمتصفح مطلقاً**: كل نداء لـ GitHub ولأي مزوّد ذكاء اصطناعي يتم من السيرفر (PHP) حصراً؛ متصفح المستخدم لا يرى المفتاح لا في HTML ولا في طلبات AJAX.
- **صلاحيات الوصول**: صفحة `users.php` وكل إجراء إداري محمي بـ `require_admin()`. صفحات المشاريع محمية بـ `require_login()` مع تحقق إضافي من الملكية أو دور المسؤول قبل الأرشفة أو الحذف.
- **ترويسات أمان HTTP**: `X-Content-Type-Options`, `X-Frame-Options: DENY`, `Referrer-Policy`, `Content-Security-Policy`, `Permissions-Policy` على كل صفحة.
- **حماية على مستوى الملفات**: `.htaccess` يمنع الوصول المباشر لمجلدات `config/` و`includes/` و`services/` و`database/` وأي ملف إعداد أو SQL.

## استخدام قسم "السياق والإعدادات" لكل مشروع

داخل كل مشروع (`project_context.php`) تبويب **"السياق والإعدادات"** يتيح حفظ:

1. **هيكل قاعدة البيانات (SQL Schema)** — يُلصق فيه مخطط الجداول الخاص بالمشروع.
2. **قواعد المشروع البرمجية (System Rules)** — توجيهات ثابتة (أسلوب الكود، المكتبات المسموحة...).
3. **بيانات GitHub** — Owner/Organization، اسم المستودع، الفرع، وPersonal Access Token.
4. **مزوّدو الذكاء الاصطناعي (متعددون)** — بطاقة "مزوّدو الذكاء الاصطناعي" تتيح إضافة
   أي عدد من المفاتيح: أكثر من مفتاح NVIDIA NIM (مثلاً للتبديل بينها أو كنسخة احتياطية)،
   أو أي مزوّد آخر متوافق مع بنية OpenAI Chat Completions API (OpenAI، Groq، DeepSeek،
   Together AI، OpenRouter، Mistral، أو نموذج مستضاف ذاتياً) بتحديد نقطة الاتصال
   (Base URL) الخاصة به. كل مزوّد له تسمية، مفتاح API خاص، نموذج نص، ونموذج رؤية
   اختياري، ويمكن تعيين واحد كـ"افتراضي". من تبويب "المساعد الذكي" يظهر قائمة منسدلة
   لاختيار أي مزوّد مُسجَّل تريد استخدامه لكل رسالة.

عند أي رسالة في تبويب **"المساعد الذكي"**، يقوم `AiClient::buildSystemPrompt()`
بحقن هيكل قاعدة البيانات وقواعد المشروع (وملف GitHub المُرفَق إن وُجد) تلقائياً
ضمن System Prompt المُرسَل إلى نقطة اتصال المزوّد المختار (الافتراضية: NVIDIA NIM
عبر `https://integrate.api.nvidia.com/v1/chat/completions`، بنفس بنية استدعاءات
OpenAI API)، مع إمكانية إرفاق صورة لتحليلها عبر نموذج رؤية، وزر "رفع إلى GitHub"
على أي كتلة كود في رد المساعد لإنشاء Commit مباشر على الفرع المحدد (يحدَّد الملف
الموجود تلقائياً لتحديثه، أو يُنشأ كملف جديد).

### الترقية من نسخة سابقة (مفتاح NVIDIA واحد فقط)

إن كنت قد ثبّتّ نسخة سابقة من النظام (بها `config/config.php` موجود بالفعل)،
شغّل `database/migrate_ai_providers.sql` مرة واحدة على قاعدة بياناتك — ينشئ
جدول `ai_providers` وينقل مفتاح NVIDIA المحفوظ سابقاً (إن وُجد) كأول مزوّد
افتراضي تلقائياً، دون أي حذف أو فقدان لبياناتك الحالية.
