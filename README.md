# واصل — منصة حملات واتساب متعددة الفروع

تطبيق ويب (Flask + Selenium) لإدارة حملات واتساب: أدمن واحد ثابت بالكود يملك
لوحة تحكم كاملة، ومنها ينشئ حسابات فروع (بريد وكلمة مرور خاصين بكل فرع) تسجّل
دخولها بشكل مستقل وتدير حساباتها وحملاتها بمعزل تام عن باقي الفروع. كل حساب
(أدمن أو فرع) يقدر يربط عدة أرقام واتساب، ويرسل حملات نصية فورية أو مجدولة
بموعد واحد أو **مقسّمة على عدة أيام** (مثلاً: 80 رقم بمعدل 20 يومياً على 4 أيام
تلقائياً). ما فيه اشتراكات أو فترة تجريبية.

## المزايا

- أدمن المنصة حساب ثابت بالكود (`ADMIN_EMAIL`/`ADMIN_PASSWORD`) — يُنشأ أو
  يُحدَّث تلقائياً بكل إقلاع للسيرفر. ما فيه تسجيل حساب جديد من الموقع إطلاقاً.
- الأدمن فقط ينشئ حسابات الفروع (بريد وكلمة مرور مستقلين لكل فرع) من قسم
  "الفروع" بلوحته. كل فرع بياناته (حسابات واتساب، حملات، سجل) معزولة تماماً.
- صلاحيات حساب الفرع محصورة بثلاثة أشياء فقط: إدارة حسابات واتساب (إضافة/حذف)،
  إدارة الحملات، والإشعارات — بدون وصول لأي إعدادات أو لوحة تحكم.
- حملات واتساب نصية فقط: أرقام تُكتب يدوياً أو تُستورد من ملف Excel، رسالة
  نصية مع حقل رابط منفصل (يُدمجان تلقائياً بالرسالة المرسلة).
- رمز الدولة: الأرقام تُكتب محلياً بدون رمز دولي، مع قائمة اختيار فوق حقل
  الأرقام لتحديد رمز الدولة الافتراضي (العراق `964+` افتراضياً).
- جدولة الحملة: إرسال فوري، أو بموعد واحد، أو تقسيم القائمة على عدة أيام (حدّد
  عدد الأرقام باليوم أو عدد الأيام) مع وقت إرسال يومي ثابت — تشتغل تلقائياً حتى
  لو السيرفر انطفى وانرجع اشتغل (يلحق الدفعات المتأخرة).
- تطبيق PWA (يُضاف للشاشة الرئيسية).

## التشغيل

```bash
pip install -r requirements.txt
python webapp.py
```

ثم افتح `http://localhost:5000` (أو `http://IP_السيرفر:5000` على VPS). يحتاج
Chrome/Chromium و chromedriver مثبّتين على نفس الجهاز (تحكم كل حساب واتساب عبر
متصفح Selenium منفصل، ويربط جلسته بمجلد `wa_sessions/` فلا يحتاج مسح QR من جديد
بعد كل إعادة تشغيل).

### بيانات دخول الأدمن

قبل أي تشغيل فعلي على الإنترنت، غيّر بيانات دخول الأدمن الثابتة، إما بتعديل
`ADMIN_EMAIL`/`ADMIN_PASSWORD` أعلى `webapp.py` مباشرة، أو بمتغيرات بيئة (الأفضل
حتى لا تُحفظ كلمة المرور الحقيقية بالكود):

```bash
export ADMIN_EMAIL="you@example.com"
export ADMIN_PASSWORD="اختر-كلمة-مرور-قوية"
python webapp.py
```

هذا هو حساب الدخول الوحيد الذي يملك لوحة تحكم؛ كل الحسابات الأخرى هي فروع
ينشئها الأدمن نفسه من داخل لوحته.

## ملاحظة مهمة

التحكم بواتساب هنا عبر أتمتة متصفح (Selenium) لواجهة واتساب ويب، وهذا يخالف
شروط استخدام واتساب الرسمية للإرسال الآلي/الجماعي. استخدمه على مسؤوليتك، ولأرقام
وافقت فعلاً على استقبال رسائلك (تسويق لعملائك الحاليين مثلاً)، لا لإرسال رسائل
غير مرغوبة أو حملات جماعية عشوائية.
