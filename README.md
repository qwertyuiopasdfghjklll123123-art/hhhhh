# نظام إدارة شركة الصوى للصرافة

نظام PHP + MySQL لإدارة الفروع والموظفين والحضور والرواتب والطلبات، بثلاث لوحات تحكم حسب الصلاحية:

- **الموارد البشرية (HR)** — `hr.php`: يدير كل الفروع، وله صلاحية إضافة/تعديل أي موظف في أي فرع، مراجعة كل الطلبات، الرواتب، سعر الصرف، وإعدادات النظام.
- **مدير الفرع** — `branch.php`: يدير موظفي فرعه فقط، الحضور والبصمة، طلبات موظفيه، والإيجاز اليومي (الإيرادات والمصروفات).
- **الموظف** — `employee.php`: تسجيل حضور/انصراف ذاتي، تقديم طلبات (إجازة/سلفة/شكوى/استقالة)، عرض ملفه الوظيفي وراتبه.

كل لوحة مكتوبة في **ملف واحد** يحتوي قسمين واضحين داخلياً: منطق PHP في الأعلى، ثم واجهة HTML في الأسفل (مفصولة بتعليق `الواجهة`).

## هيكل المشروع

```
install.php          مثبّت تلقائي (Auto-Installer): ينشئ القاعدة والجداول والحساب الأول
login.php             تسجيل الدخول لكل الأدوار
logout.php
index.php             موجّه تلقائي حسب حالة الدخول
hr.php                لوحة الموارد البشرية (كل الوظائف في ملف واحد)
branch.php            لوحة مدير الفرع
employee.php          نافذة الموظف
config/
  config.sample.php   نسخة مرجعية فقط — لا تُستخدم مباشرة
  config.php          يُنشأ تلقائياً بعد التثبيت (غير موجود في المستودع)
includes/
  schema.php          تعريف الجداول والبيانات الافتراضية (Seed)
  db.php               اتصال PDO
  auth.php             الجلسات وصلاحيات الأدوار
  functions.php        دوال مساعدة عامة (CSRF، تنسيق، إشعارات...)
  bootstrap.php         نقطة تحميل موحّدة تُستدعى في بداية كل صفحة
assets/
  css/style.css        التصميم العام (RTL)
  js/app.js             تفاعلات بسيطة (قوائم، تنبيهات، تأكيد الحذف)
uploads/               مجلدات لرفع الصور والمستندات لاحقاً
```

## التثبيت على الاستضافة (cPanel / Hostinger وغيرها)

1. ارفع محتويات المشروع بالكامل إلى مجلد `public_html` (أو المجلد الفرعي الذي تريده) عبر File Manager أو FTP.
2. تأكد من أن مجلدي `config/` و `uploads/` قابلان للكتابة (عادة الصلاحية `755` أو `775` كافية على معظم الاستضافات).
3. أنشئ قاعدة بيانات MySQL فارغة ومستخدماً لها من لوحة تحكم الاستضافة (cPanel → MySQL Databases)، ثم اربط المستخدم بالقاعدة بكل الصلاحيات.
4. افتح `https://your-domain.com/install.php` من المتصفح.
5. أدخل بيانات الاتصال بقاعدة البيانات (Host غالباً `localhost`)، وبيانات حساب مدير الموارد البشرية الأول (بريد إلكتروني وكلمة مرور).
6. اضغط **تثبيت النظام الآن** — سيتم تلقائياً:
   - الاتصال بقاعدة البيانات والتحقق منه.
   - إنشاء جميع الجداول (`CREATE TABLE IF NOT EXISTS`) إن لم تكن موجودة.
   - إدراج بيانات أساسية: فرع افتراضي، إعدادات الشركة، وحساب HR الأول.
   - كتابة `config/config.php` تلقائياً ببيانات الاتصال.
7. بعد نجاح التثبيت، سجّل الدخول من `login.php` ببريد HR وكلمة المرور التي أدخلتها.

> **مهم — الأمان:** ملف `config/config.php` يحتوي بيانات اتصال قاعدة البيانات الحقيقية، ولذلك هو مُستثنى من Git عمداً (`.gitignore`). لا تضف بيانات اتصال حقيقية إلى الكود المصدري أو تدفعها إلى مستودع عام؛ يُنشئها المثبّت مباشرة على السيرفر فقط. إذا احتجت لإعادة التثبيت، احذف `config/config.php` من السيرفر أولاً.

## إنشاء الحسابات

- **HR**: يُنشأ تلقائياً أثناء التثبيت (بريد إلكتروني + كلمة مرور).
- **مدير فرع / موظف**: يُنشأ من داخل `hr.php` (تبويب "الموظفون") أو من `branch.php` (تبويب "موظفو الفرع") عند إضافة موظف جديد مع تعبئة حقل "كلمة مرور حساب الدخول". اسم المستخدم هو رقم التوظيف الذي يولّده النظام تلقائياً.

## الصلاحيات بين الأدوار

- HR يرى ويدير كل الفروع وكل الموظفين، ويراجع كل الطلبات من أي فرع.
- مدير الفرع يرى ويدير فقط موظفي فرعه، وطلباتهم، وسجل الحضور والإيجاز اليومي لفرعه.
- الموظف يرى بياناته الخاصة فقط (حضوره، طلباته، راتبه)، ويشاهد الإيجاز اليومي لفرعه للاطلاع فقط دون تعديل.

كل صفحة محمية عبر `require_role([...])`، وأي محاولة وصول من دور غير مخوّل تُرفض تلقائياً (403).
