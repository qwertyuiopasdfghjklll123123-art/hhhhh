# fastcrand — نسخة PHP / MySQL

نسخة PHP+MySQL موازية لنسخة Flask/SQLite الأصلية (`app.py`)، تُبنى بالتدريج
بنفس طريقة بناء النسخة الأصلية على مدار هذا المشروع.

## التثبيت

1. عدّل `config.php` وضع بيانات MySQL الحقيقية (الاسم/المستخدم/كلمة المرور).
2. شغّل من الترمنال:
   ```bash
   php install.php
   ```
   يتحقق السكربت من وجود `sql/schema.sql`، ينشئ قاعدة البيانات إذا لم تكن
   موجودة، ويستورد كل الجداول (25 جدول) + بيانات أولية. يمكن إعادة تشغيله
   بأمان دون تكرار البيانات.
3. بعد نجاح التثبيت **احذف `install.php` من السيرفر** لأسباب أمنية.
4. عدّل مفتاح/رابط مزوّد SMM الحقيقي من `admin/providers.php` بدل القيمة
   الوهمية المزروعة بالبذور.
5. سجّل دخول كأدمن: `admin@admin.com` / `2sebvWFr6BYwVBrV` — **غيّر كلمة
   المرور هذه فوراً**، هي نفسها الموجودة بالنسخة الأصلية وأصبحت معروفة.
6. لمفتاح المساعد الذكي: `admin/ai_settings.php` (مفتاح NVIDIA من
   build.nvidia.com).

## الميزات الجاهزة والمُختبرة فعلياً (ليس افتراضاً)

كل ما يلي رُكِّب فعلياً مع MySQL/PHP حقيقيين محلياً وجُرِّب عبر HTTP قبل
التسليم (ليس قراءة كود فقط): تثبيت الشيما + إعادة تشغيله بدون تكرار،
تسجيل دخول/خروج/حساب جديد، تعدد مزوّدي SMM (كتالوج مجمّع، كل خدمة من
مزوّدها الصحيح)، تقديم طلب (خصم رصيد صحيح + نسبة ربح مخصّصة لكل خدمة +
خصم مستوى تلقائي) مع استرجاع تلقائي عند رفض المزوّد، الإشعارات الداخلية،
شحن يدوي بإثبات دفع + موافقة/رفض أدمن، Binance Pay بتحقق تلقائي حقيقي
(HMAC)، كوبونات الهدية، المكافأة اليومية، المفضّلة، التقييمات، برنامج
الإحالة (كود + عمولة تلقائية عند إكمال المُحال طلباً)، الدعم الفني (فتح/
رد/إغلاق تذكرة)، المساعد الذكي (محادثات محفوظة، سياق حساب المستخدم
والخدمات المطابقة)، ولوحة إدارة كاملة: مستخدمين (رصيد/حظر/صلاحية)،
طلبات (تغيير حالة + استرجاع)، مزودين (CRUD كامل)، فلاتر خدمات (إخفاء/
نسبة ربح)، طرق الدفع، طلبات الشحن، كوبونات، مستويات، تذاكر، وإعدادات
الموقع — مع منع غير الأدمن من كل صفحات الإدارة (403 مؤكّد).

### لوحة الإدارة — فهرس كامل (15 قسم، كل قسم باسمه ورابطه)

صفحة `admin/index.php` الآن مُنظَّمة بـ 5 مجموعات، كل قسم فيها بطاقة
واضحة تعرض الاسم والرابط الثابت تحته مباشرة:

| المجموعة | الأقسام والروابط |
|---|---|
| المستخدمون والطلبات | 👥 `/admin/users.php` — 📦 `/admin/orders.php` |
| المزوّدون والخدمات | 🔌 `/admin/providers.php` — 🧩 `/admin/filters.php` |
| المحفظة والمدفوعات | 💳 `/admin/payment_methods.php` — 💵 `/admin/recharges.php` — 🎟️ `/admin/coupons.php` — 📊 `/admin/profits.php` |
| التفاعل والمحتوى | ⭐ `/admin/reviews.php` — 📢 `/admin/announcements.php` — 🔗 `/admin/referrals.php` — 🎫 `/admin/tickets.php` |
| النظام والإعدادات | 🏆 `/admin/levels.php` — 🤖 `/admin/ai_settings.php` — ⚙️ `/admin/settings.php` |

كل الـ 15 قسم جُرِّبوا فعلياً (200 OK + تحقق من المنطق) قبل التسليم، بما
فيها إضافات هذه الجولة: موافقة/إخفاء/حذف التقييمات (تظهر فوراً بالصفحة
العامة بعد الموافقة)، إنشاء/حذف الإعلانات (تظهر كبانر بلوحة كل مستخدم)،
صفحة الأرباح، وصفحة نظرة عامة على برنامج الإحالة.

## غير مُكتمل بعد (جولات قادمة)

- **آسياسيل**: الإعدادات (رقم الاستقبال/سعر الصرف/الحد الأقصى) جاهزة من
  لوحة الإدارة، لكن تدفق التحويل الفعلي (OTP وجلسة متعددة الخطوات، يقلّد
  تطبيق آسياسيل الرسمي) معقّد جداً وغير منقول بعد.
- **Telegram Stars**: الإعدادات جاهزة، لكن ربط البوت الفعلي (webhook،
  استلام المدفوعات من تيليجرام) غير منقول — يحتاج بوت حقيقي ورابط webhook
  عام لا يمكن اختباره من هنا أصلاً.
- إشعارات المتصفح (Web Push / VAPID) — الإشعارات الداخلية بالتطبيق فقط حالياً.
- استيراد تلقائي للخدمات الجديدة من المزوّد، النسخ الاحتياطي التلقائي،
  بوت تيليجرام للنسخ الاحتياطي.
- الخدمات المخصّصة (custom_services/custom_orders) — جدولها جاهز، بلا واجهة.
- سلة التسوق (طلب خدمات متعددة دفعة واحدة) — نسخة PHP تدعم طلب واحد بالمرة.
- التحقق من البريد عبر كود (SMTP) — كل الحسابات الجديدة بهذه النسخة مُفعّلة مباشرة.
- تسجيل الدخول بجوجل (Google OAuth).
- صفحة رئيسية تسويقية (Landing page) للزوار غير المسجّلين — حالياً كل من
  يزور الموقع بدون تسجيل دخول يُحوَّل لصفحة تسجيل الدخول مباشرة.
- طرق الدفع اليدوية: صورة الإثبات تُخزَّن كملف (ليس base64 كالأصل)، وهذا
  تحسين متعمّد لا يغيّر الوظيفة.
