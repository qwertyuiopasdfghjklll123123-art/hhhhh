# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS/JS, no build step, no framework. Chosen explicitly by the user over a framework option for a single landing page.

## Users

Arabic-speaking shoppers looking to buy a phone from a shop they can trust — deciding whether to reach out and order, not filling out a self-serve checkout.

## Product Purpose

A single professional landing page for a phone retail shop: present the shop and its phones convincingly enough that a visitor contacts the shop to order. No cart, no online payment — ordering happens by contacting the shop directly (WhatsApp), which the user chose explicitly over a full store build.

## Positioning

A boutique, single-object-at-a-time presentation of each phone (name, key specs, price) rather than a dense marketplace grid — the shop reads as a curated, trustworthy retailer rather than a bulk reseller. Differentiator is craft and trust signals (warranty, quality-check, fast delivery), not price competition, which is not evidenced yet.

## Operating Context

Single page, no backend, deployable anywhere static files can be hosted. Ordering flow is entirely external (WhatsApp / contact), so no user accounts, cart state, or payment integration exist or are needed for this surface.

## Capabilities and Constraints

- No real shop name, phone number, address, or social links were supplied yet. The shipped page uses clearly-labeled placeholder contact details and a placeholder shop name that must be swapped before going live.
- No real product catalog, prices, or photography were supplied. The shipped page uses an authored placeholder catalog (fictional model names, illustrative specs/prices) built as real design material, not lorem ipsum, but explicitly not real inventory — replace before launch.
- No image-generation tool is available in this environment, so all imagery is built from CSS/SVG rather than generated or stock photography.

## Brand Commitments

Color identity is pinned by the user: green and white, "professional" in tone. Everything else (name, exact palette values, typography, product photography) was left to be designed.

## Evidence on Hand

None yet — this is a from-scratch build with no existing repo content, copy, or assets beyond this PRODUCT.md and the pinned color brief.

## Product Principles

- Each phone is presented like something worth wanting, not a row in a spreadsheet.
- Trust is shown through specifics (named guarantees, real-sounding policies), not generic badges.
- Every claim the page cannot back with real data is either omitted or clearly marked as a placeholder for the shop owner to fill in — nothing invented is presented as verified fact.
- The path to buying is always one visible tap away: contact the shop.
