# واصل — منصة حملات واتساب متعددة الفروع (PHP لاستضافة cPanel)

منصة لإدارة حملات واتساب لعدة فروع، تشتغل على **استضافة cPanel عادية (PHP + MySQL)**
بدون VPS وبدون أي اشتراك أو خدمة خارجية مدفوعة.

## كيف يشتغل

```
 الأدمن والفروع (أي متصفح/جوال)          كمبيوتر الفرع (كروم + واتساب ويب)
            │                                         │
            ▼                                         ▼
   ┌──────────────────┐   "شنو الرسالة الجاية؟"  ┌────────────────────┐
   │ الموقع على cPanel │ ◄──────────────────────── │ إضافة واصل لكروم   │
   │  PHP + MySQL     │ ────────────────────────► │ ترسل عبر واتساب ويب │
   └──────────────────┘   الرقم + النص ← النتيجة   └────────────────────┘
```

- **الموقع** (هذا المستودع) يرتفع على cPanel: فيه الدخول، الفروع، الحملات، الجدولة،
  الإحصائيات، والإشعارات. يحفظ كل رسالة بطابور مع موعدها.
- **الإرسال** يتم من كمبيوتر الفرع عبر **إضافة كروم مجانية** (مجلد `extension`): تستخدم
  واتساب ويب المفتوح على الكمبيوتر، تسحب الرسائل المستحقة من الموقع وحدة وحدة، ترسلها،
  وتبلّغ بالنتيجة. الموقع ينزّلها للفرع جاهزة ومربوطة بحسابه تلقائياً.
- الاستضافة المشتركة ما تقدر تشغّل متصفح ولا برامج بالخلفية، لهذا الإرسال على جهاز
  الفرع — وما تحتاج تضبط أي Cron.

## المزايا

- **أدمن واحد ثابت بالكود** (بريد وكلمة مرور بملف `inc/core.php`) — ما فيه تسجيل حساب من الموقع.
- **الأدمن فقط ينشئ الفروع**: اسم + بريد + كلمة مرور (أو مولّدة تلقائياً)، ويقدر يغيّر كلمة مرور
  أي فرع (يطلع من كل أجهزته) أو يحذفه.
- **صلاحيات الفرع**: حسابات واتساب، الحملات، والإشعارات فقط — وبياناته معزولة عن باقي الفروع.
- **حملات نصية**: حقل للنص وحقل للرابط (يُضاف بآخر الرسالة)، بدون مرفقات صور/ملفات.
- **الأرقام** تُكتب أو تُرفع من Excel (.xlsx) أو CSV — يتعرّف على عمود الأرقام تلقائياً،
  ويحذف المكرر والناقص، ويقبل الأرقام العربية (٠٧٧٠…).
- **رمز الدولة**: قائمة أعلى حقل الأرقام (العراق 964 افتراضياً) — اكتب الأرقام محلياً
  (07701234567) والرمز ينضاف تلقائياً. الرقم المكتوب دولياً (+971…) يبقى كما هو.
- **الجدولة**: إرسال فوري، أو بموعد واحد، أو **تقسيم على أيام** (مثلاً 80 رقم ← 20 يومياً
  على 4 أيام بوقت ثابت)، مع إلغاء يوم معيّن أو الحملة كاملة.
- **متابعة حيّة**: تقدّم كل حملة، الأرقام الفاشلة وسببها، حالة جهاز الإرسال لكل حساب.
- **إشعارات** داخل الموقع وبالمتصفح (بدأت/اكتملت الحملة، اكتمل يوم، جهاز الإرسال يحتاج QR…).
- **لوحة الأدمن**: إحصائيات كل الفروع، ترتيب الفروع حسب نسبة النجاح، تغيير اسم وشعار الموقع.
- **تطبيق PWA** يتثبّت على الجوال والكمبيوتر، وتصميم لسطح المكتب (شريط جانبي) يتحول لقائمة على الجوال.

## التثبيت على cPanel (مرة وحدة)

1. **ارفع الملفات**: cPanel ← File Manager ← `public_html` (أو مجلد فرعي) ← Upload لملف
   الـ zip ← Extract. لازم يكون `index.php` مباشرة داخل المجلد.
2. **أنشئ قاعدة بيانات**: cPanel ← MySQL Databases:
   - أنشئ قاعدة بيانات (مثلاً `user_wasel`) ومستخدم بكلمة مرور.
   - Add User To Database ← اختر ALL PRIVILEGES.
3. **افتح المثبّت**: `https://دومينك/install.php` ← أدخل بيانات قاعدة البيانات (السيرفر
   غالباً `localhost`) ← "تثبيت النظام الآن".
4. **احذف `install.php`** من مدير الملفات بعد نجاح التثبيت (للأمان).
5. **ادخل بحساب الأدمن** من `https://دومينك/`.

المتطلبات: PHP 7.4 أو أحدث (يُفضّل 8.1+) مع إضافة `pdo_mysql`. ويُفضّل تفعيل `zip` و`gd`
و`mbstring` من cPanel ← Select PHP Version ← Extensions (المثبّت يفحصها لك). فعّل
شهادة SSL المجانية (AutoSSL) حتى يشتغل الموقع على `https`.

## تجهيز جهاز الإرسال بكل فرع

يتم من حساب الفرع نفسه ← **حسابي**:

1. "إضافة حساب" (اسم لرقم الواتساب، مثل: واتساب المبيعات).
2. "تحميل الإضافة" ← ملف zip جاهز ومربوط بهذا الحساب.
3. فك الضغط بمكان ثابت ← افتح Google Chrome واكتب `chrome://extensions` ← فعّل
   "وضع المطوّر" ← "تحميل إضافة غير مضغوطة" (Load unpacked) ← اختر مجلد `wasel-sender`.
4. ينفتح تبويب واتساب ويب تلقائياً ← امسح رمز QR من الجوال (واتساب ← الأجهزة المرتبطة ← ربط جهاز).
5. خلّي كروم مفتوح. حالة الحساب بالموقع تصير **متصل** خلال دقيقة، وأي حملة تنرسل تلقائياً.

أيقونة واصل بشريط إضافات كروم تعرض: حالة الاتصال، رسائل اليوم، سجل آخر العمليات، وزر
إيقاف مؤقت. وتشتغل كذلك على Microsoft Edge (`edge://extensions`).

## بيانات دخول الأدمن

موجودة أعلى ملف `inc/core.php`:

```php
define('ADMIN_EMAIL', 'fastcrand@gmail.com');
define('ADMIN_PASSWORD', 'fastcrand1');
```

لتغييرها عدّل السطرين وارفع الملف من جديد. لا تشارك هذا الملف ولا تخلّي المستودع عام.

## ملفات المشروع

| الملف/المجلد | الوظيفة |
|---|---|
| `index.php` | الموقع: شاشة الدخول، لوحة التحكم، وواجهة JSON (`?api=`) |
| `agent.php` | نقطة اتصال إضافة كروم (بمفتاح ربط لكل حساب واتساب) |
| `install.php` | المثبّت: ينشئ الجداول ويكتب `config.php` |
| `inc/` | منطق النظام (قاعدة البيانات، الحملات، الصلاحيات) — محمي من المتصفح |
| `assets/` | التصميم والواجهة والخطوط والأيقونات (كلها محلية بدون مواقع خارجية) |
| `extension/` | كود إضافة كروم (الموقع يجهّزها للتحميل مع بيانات الربط) |
| `uploads/` | شعار الموقع المرفوع |
| `config.php` | بيانات قاعدة البيانات — ينشئه المثبّت على السيرفر فقط (مستثنى من Git) |

## حل المشاكل

- **الحساب "غير متصل"**: كمبيوتر الفرع مطفأ أو كروم مسكّر. الرسائل ما تضيع — تنتظر وتنرسل أول ما يتصل.
- **"يحتاج مسح QR"**: واتساب ويب طلع من الجلسة. افتح تبويبه على جهاز الفرع وامسح الرمز.
- **حسابين واتساب على نفس الكمبيوتر**: استخدم ملفي تعريف (Profiles) بكروم، وبكل ملف تعريف حمّل
  إضافة الحساب الخاص فيه.
- **نقل الإضافة لجهاز ثاني**: حمّلها من جديد من الموقع (التحميل الجديد يوقف النسخة القديمة تلقائياً).
- **الإرسال بطيء والكمبيوتر مو مستخدم**: خلّي نافذة واتساب ويب مفتوحة ومو مصغّرة.
- **رسالة فشلت بسبب "تعذّر تأكيد الإرسال"**: إذا تكرر مع كل الأرقام فواتساب ويب غيّر واجهته —
  أرسل لقطة من سجل الإضافة لتحديثها.

## ملاحظة مهمة

الإرسال الآلي عبر واتساب ويب يخالف شروط استخدام واتساب للرسائل الجماعية، ويمكن يتحظر الرقم
إذا انرسلت رسائل كثيرة لأرقام ما تعرفك. استخدمه لعملائك اللي وافقوا يستلمون رسائلك، وخلّي
الفاصل بين الرسائل 15 ثانية أو أكثر، ووزّع القوائم الكبيرة على أيام.
